# PopX Account Management App

This is a simple React application that provides user account functionality including:

- User Signup
- User Sign-in (with credential validation)
- Account Settings page (displays user info)
- Routing using React Router
- Data persistence using `localStorage`

---

## 🧑‍💻 Features

- **Signup Page**  
  Users can register with full name, email, password, phone, and agency status. Data is saved in localStorage.

- **Sign-in Page**  
  Users can log in with their registered email and password. If valid, they are redirected to the account settings page.

- **Account Settings Page**  
  Displays user's name, email, and a placeholder profile section.

---

## 🛠 Technologies Used

- React (Vite or CRA)
- React Router DOM
- Tailwind CSS
- Lucide React (for icons)
- LocalStorage (for persistence)
